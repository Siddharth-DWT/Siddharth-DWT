**What I work on**

- **Agents** — multi-agent workflows with LangGraph and LangChain, human-in-the-loop, tool use

- **MCP** — remote MCP servers with OAuth, SDKs and agent tooling
- **Web data for LLMs** — crawlers that turn bot-protected sites into clean markdown
- **Full stack** — Next.js, React, TypeScript, Python, FastAPI, Postgres, MongoDB

### Featured work

**[MeshArc](https://github.com/mesharc-org)** — a web crawler and scraper for AI agents: search, scrape, map and crawl sites to clean markdown, and track what changes.

| Repo | What it is |
| --- | --- |
| [mesharc-mcp](https://github.com/mesharc-org/mesharc-mcp) | MCP server: crawl and scrape websites from any MCP client |

| [mesharc-node](https://github.com/mesharc-org/mesharc-node) | Official Node.js client |
| [claude-code-plugin](https://github.com/mesharc-org/claude-code-plugin) | MeshArc for Claude Code: search, scrape, map and crawl from the terminal |

**[agentic-rag-platform](https://github.com/Siddharth-DWT/agentic-rag-platform)** — an open reference app for agentic RAG: LangGraph agent, LlamaIndex retrieval, FastAPI streaming backend and a Next.js chat UI. *In active development.*

**[NEXUS](https://github.com/Siddharth-DWT/behaviour-analysis)** — a multi-agent system that analyses calls and meetings across voice, language, face, body, gaze and conversation, then fuses them to catch what a single channel misses.
